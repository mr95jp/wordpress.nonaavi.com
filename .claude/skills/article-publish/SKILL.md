# 記事を公開できる状態にする

`status: draft` の記事は noindex でサイトマップにも載らない。
この手順を終えた記事だけを `published` にする。

**記事の中身（実測値・結論・手順の意味）は変えない。**変えるのは、読者の環境で
使えない記述・リンク・メタ情報だけ。

## 1. 現状を取る

```sh
pnpm build && pnpm check:site --slug <slug>
```

記事本文を最後まで読む。

## 2. 結論ボックス

`summary` が無ければ **article-summary** スキルの手順で書く。

## 3. ラボ専用の記述を読者向けにする

check:site が「再現手順の外にラボ専用の記述」と出したものを直す。
`## 再現手順` の節（自動で折りたたまれる）の中は、実測の証拠なのでそのまま残す。

| 本文にあるもの | 直し方 |
|---|---|
| `http://localhost:8080` / `8082` | `https://example.com` |
| `bin/diagnose.sh` などラボのスクリプト | 同じことをする curl などのコマンドに置き換える。置き換えられなければ文ごと消す |
| `docker compose ...` | 再現手順の節へ移す |
| `src/wp-content/...` | `wp-content/...` |
| 「このラボでは」 | 「検証環境では」 |

**残すもの**: エラーメッセージやスタックトレースの中のパス・プラグイン名
（`lab-legacy-php` など）。実際の出力なので書き換えると証拠でなくなる。

再現手順の見出しが `## 再現手順` で始まっていないと折りたたまれない。

## 4. 内部リンク

```sh
# この記事へのリンク（ほかの記事から）
grep -ln '](<slug>.md)' src/content/articles/*.md
# この記事からのリンク
grep -o '](\([a-z0-9-]*\)\.md)' src/content/articles/<slug>.md
```

- **ほかの記事へのリンクが 2 本未満なら足す。**同じハブ（`src/lib/hubs.ts`）の記事か、
  症状が隣り合う記事へ。本文中で関連する事実に触れている箇所に置く
- **ほかの記事から 1 本もリンクされていなければ**、関係する記事に 1 本足す
- リンク文は記事タイトルではなく症状の言葉にする（「ログイン画面に戻される場合は」）
- リンクは `[文言](other-slug.md)` の形で書く（ビルドで `/other-slug/` に変換される）

## 5. タイトルと狙い語

```sh
grep -h '^keywords:' src/content/articles/*.md | tr ',' '\n' | sort | uniq -d
```

- ほかの記事と同じ語を狙っていたら、中身に合うほうへ寄せて片方の語を外す
- 「WordPress 真っ白」のような広い語は症状別ハブが受ける。個別記事は具体的な語にする
- `title` は H1、`seo_title` は検索結果のタイトル。どちらも中身より広いことを言わない

## 6. スクリーンショット

画面に症状が出る記事なら、その画面の画像が 1 枚以上あるか確認する。
無ければ公開を止めてユーザーに伝える（撮影はラボでしかできない）。
alt には画面に出ている文言を入れる。

## 7. 公開する

front matter を更新する。

```yaml
status: published
published: 2026-09-20   # 今日の日付
```

本文を大きく直した場合は `updated:` も今日にする。`verified:`（実測した日）は変えない。

## 8. 確認

```sh
pnpm build && pnpm check:site --slug <slug>
```

- エラーが 0 件
- この記事に警告が出ていない
- サイトマップに載っている（published なのに載っていなければエラーになる）

## 9. TODO を更新する

`docs/todo.md` から公開した記事を消し（チェックを付けるか行を削除し）、冒頭の「公開済み・下書き」の本数と最終更新日を直す。
スクリーンショットが無くて公開を止めた記事は、撮る画面を具体的に `docs/todo.md` の 1 に書き足す。

最後に、直した内容を箇条書きでユーザーに報告する。
サイト側の記事はラボの元記事と内容が変わるので、そのことも一言添える。
